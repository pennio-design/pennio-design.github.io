# "Architecture First" — PENNIO Founder Acquisition Campaign

Positions PENNIO as the brand architecture studio for visionary founders: the
partner that builds the meaning, system, and voice a founder's brand stands
on, before web and growth spend get involved. Copy pulls directly from
PENNIO's live site language ("brand architecture," "one connected system,"
the manual-review / 48-hour-response intake model) rather than inventing new
claims — every stat and process detail here is consistent with `index.html`.

## Audience

Visionary founders past the idea stage: product is real, the market is
real, and the current brand is either generic or assembled from disconnected
vendors. Primarily African founders scaling past their home market, per
PENNIO's existing positioning.

## Single-Ad Concepts (3 headline variants, for split testing)

Each ships as a self-contained HTML file with a 1:1 / 4:5 / 9:16 format
switcher and a 3× PNG export button. Pre-rendered PNGs for all three formats
are in `exports/`.

1. **`flyer-authority.html`** — reframe hook. *"Your brand is not a logo.
   It's the architecture everything else stands on."* Leads with authority:
   redefines the category before asking for anything.
2. **`flyer-cost.html`** — cost/agitation hook. *"Stop paying ads to send
   traffic to a brand that hasn't decided what it is."* Targets founders
   already spending on paid media without a foundation to hold it.
3. **`flyer-exclusivity.html`** — selection hook. *"We don't build brands
   for everyone. Only founders building something real."* Leans on
   PENNIO's actual limited-intake model to create qualified urgency.

Run these as parallel ad sets on the same budget and let performance decide
which hook a given audience segment responds to — that's the point of
shipping three angles instead of one.

## Carousel Ad

**`carousel.html`** — 9-slide narrative arc for Meta and LinkedIn carousel
placements (and organic IG/LinkedIn posting): the pattern founders fall
into (ship the brand fast, turn ads on, traffic bounces, budget gets cut),
why that's an architecture problem and not an ad problem, what PENNIO
actually builds, and who gets accepted into the studio. Ends on the
domain only, no button language. Includes per-slide PNG export, a batch
"all 9 PNGs" export, and a one-click PDF deck — open the file and use the
toolbar.

## Format Guidance

- **1:1** — LinkedIn, X/Twitter, Meta feed
- **4:5** — Meta/Instagram feed (best default engagement)
- **9:16** — Instagram/Facebook Stories, Reels cover frame

## Voice Rules Applied

No em dashes. No filler transitions or corporate abstraction. Every claim
in the copy (48-hour response, manual review, limited intake) is a real
operating detail already stated on pennio.agency, not a fabricated stat.
